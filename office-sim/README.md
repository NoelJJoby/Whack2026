# Office Sim

Minimal project skeleton for an office simulation app.

## Setup

1. Copy `.env.example` to `.env`.
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Run the app:
   ```bash
   pnpm run dev
   ```
4. Open the client in a browser on the Vite URL printed in the terminal.

## Notes

- This is intentionally a basic structure only.
- The server, simulation rules, and client views are placeholders.
- Add the simulation logic later as needed.
